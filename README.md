# Setup
1. Run the game normally once.
2. Download the [BepInEx](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.4/BepInEx_win_x86_5.4.23.4.zip) and extract it to the game folder.
3. open solution, tweak the dependencies `Assembly-CSharp.dll` and `BepInEx.Harmony.dll`.
4. Generate the project and place it in the plugin directory.(You can enable the plugin log for debugging)
